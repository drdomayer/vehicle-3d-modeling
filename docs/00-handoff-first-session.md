## Какво да очакваш

- Claude Code ще види картинките (чете image файлове от диска).
- Клетката ще се появи в Blender в колекция CAGE_986. Червените елементи са
  TODO позиции (стъкло, roll hoops, страничен отвор), сивите — публикувани
  размери, оранжевото — STATEV target envelope.
- Всичко, което решите занапред, Claude Code трябва да записва в
  `docs/09-decision-log.md` и в секцията "Current status" на `CLAUDE.md`.
  Напомняй му: "запиши това в decision log".

- Blender ръчно за форма; Claude Code за скриптове, измервания, проверки,
  разрязване, експорт, git commit-и.
- Commit при всеки завършен етап.
- Чатът в claude.ai остава за стратегия/рендери/промптове към ChatGPT;
