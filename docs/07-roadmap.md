# 07 — Roadmap

## Фаза 0 — Дигитална клетка (сега, без донор)

1. `01_CAD/scripts/cage_986.py` → клетка с публикуваните размери.
2. Чертеж 986 (the-blueprints.com) като Reference Images в 3 равнини; мащаб по
   междуосието 2416/2418.
3. 3D артистичен модел на 986 като полупрозрачна подложка (стъкло, hoops,
   врати, страничен отвор, капак).
4. 20–30 снимки на реални 986 от обяви за детайли.
5. Поръчка на Hella модули (или поне техните размери от каталога) — дизайнът
   на маската е около тях.

## Фаза 1 — Учене + първи повърхности (в Blender, ръчно; Claude чрез MCP за
клетка, измервания, проверки, разрязване)

1. Огледало → нов капак → печат → монтаж (една седмица, целият workflow).
2. Корпус за Hella модул.
3. **Преден калник** — първата голяма повърхност. Ако той се получи, останалото
   е повторение. Ще се прави 2–3 пъти — нормално.
4. Скенер (Range 2 / POP 3) — учене върху огледалото/калника.

## Фаза 2 — Донор

Купуване на 986 (2003–04 предпочитан), IMS/съединител, скан по
`docs/02-hardpoints-986.md`, подравняване на клетката към скана, корекция на
готовите повърхности (дни, ако повърхностите са чисти).

## Фаза 3 — Пълен екстериор в CAD

Front clamshell, deck + перки + квартери, задна броня/дифузьор, врати/прагове,
дребни части. Инженерни проверки: клирънс на колелата, път на покрива,
позиции на светлините, достъп до двигателя, охлаждане.

## Фаза 4 — Печат и монтаж

Тестов калник → корекция → останалото, по реда в `05-manufacturing-workflow.md`.

## Фаза 5 — Композит, боя, интериор, сглобяване

## Фаза 6 — Валидация и регистрация

Структура, спирачки, кормилна, светлини, гуми, окачване, топлина, крепежи,
индивидуално одобрение.

## Фаза 2-plus (по-късно)

Свалящ се композитен hardtop (fastback с buttress-и), 3.4/3.6 swap, собствен
голям принтер, кит/услуга.
